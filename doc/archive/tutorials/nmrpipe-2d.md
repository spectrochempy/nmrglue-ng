# 2D NMRPipe data: axes and contours

**{nb-download}`Download notebook (.ipynb) <nmrpipe-2d.ipynb>`**
· {download}`Download synthetic data (nmrpipe_2d_freq.ft2) <../../../tests/fixtures/fileio/data/nmrpipe_2d_freq.ft2>`

This tutorial reads a compact **synthetic** 2D NMRPipe frequency-domain fixture,
builds one unit-conversion axis per dimension, and draws a simple contour plot.

The fixture is versioned in this repository at
`tests/fixtures/fileio/data/nmrpipe_2d_freq.ft2`. It was generated by
`tests/fixtures/fileio/create_test_data_nmrpipe.sh` from synthetic time-domain
data with `H1` as the direct dimension and `C13` as the indirect dimension. It
is not a real acquisition.

Relevant API entries: {func}`nmrglue.fileio.pipe.read`,
{func}`nmrglue.fileio.pipe.guess_udic`, and
{func}`nmrglue.fileio.fileiobase.uc_from_udic`.

## 1. Prepare your working folder

Start with the [1D tutorial](nmrpipe-1d.md) if you are new to reading NMRPipe
files. Here you will reuse its read–inspect–plot sequence, assigning a separate
chemical-shift axis to each array dimension.

Download both files above into the same folder, keeping their filenames.
Use a Python environment with nmrglue-ng, Matplotlib, and a Jupyter frontend
installed. Install the package and notebook tools with
`python -m pip install nmrglue-ng matplotlib jupyterlab`.
Launch `jupyter lab` from the download folder, select that environment's kernel,
and run the notebook from top to bottom.

The code first looks in the current working folder. The fallback to the
repository fixture is only for building the documentation from its sources.

## 2. Read and identify the dimensions

```{code-cell} ipython3
from pathlib import Path

import matplotlib.pyplot as plt
import nmrglue as ng


def find_data_file(filename):
    local_path = Path(filename)
    if local_path.is_file():
        return local_path
    for candidate in [Path.cwd(), *Path.cwd().parents]:
        fixture = candidate / "tests/fixtures/fileio/data" / filename
        if fixture.is_file():
            return fixture
    raise FileNotFoundError(
        f"Download {filename} into the notebook's working folder: {Path.cwd()}"
    )


path = find_data_file("nmrpipe_2d_freq.ft2")
dic, data = ng.pipe.read(path)

print(f"Array shape (indirect points, direct points): {data.shape}")
print(f"Array data type: {data.dtype}")
```

The array shape follows NumPy order: the first axis is the indirect dimension
and the last axis is the direct dimension. For this fixture, the header labels
the dimensions as `C13` and `H1`.

## 3. Construct one axis per dimension

```{code-cell} ipython3
udic = ng.pipe.guess_udic(dic, data)
uc_indirect = ng.fileiobase.uc_from_udic(udic, dim=0)
uc_direct = ng.fileiobase.uc_from_udic(udic, dim=1)

for dim in range(data.ndim):
    print(f"Dimension {dim}: {udic[dim]['label']}, {data.shape[dim]} points")
    print(f"  Spectral width: {udic[dim]['sw']:.2f} Hz")
    print(f"  Observation frequency: {udic[dim]['obs']:.2f} MHz")
    print(f"  Frequency-domain data: {udic[dim]['freq']}")
```

`dim=0` creates the indirect `C13` axis and `dim=1` creates the direct `H1`
axis. Both axes are in ppm below; use Hz with `hz_scale()` when comparing
directly against header spectral widths or processing parameters.

## 4. Match the contour coordinates to the array

Columns (the last array dimension, `H1`) map to the horizontal axis; rows
(`C13`) map to the vertical axis. The two contour levels below are intensities
in arbitrary units, chosen only to illustrate this small fixture.

```{code-cell} ipython3
:tags: [hide-input]

ppm_indirect_axis = uc_indirect.ppm_scale()
ppm_direct_axis = uc_direct.ppm_scale()

fig, ax = plt.subplots(figsize=(6, 4))
levels = [0.5, 1.5]
print(f"Contour levels (arbitrary units): {levels}")
ax.contour(
    ppm_direct_axis,
    ppm_indirect_axis,
    data.real,
    levels=levels,
    colors="navy",
)
ax.set_xlabel(f"{udic[1]['label']} chemical shift / ppm")
ax.set_ylabel(f"{udic[0]['label']} chemical shift / ppm")
ax.set_title("Synthetic 2D NMRPipe fixture")
ax.invert_xaxis()
ax.invert_yaxis()
fig.tight_layout()
plt.show()
```

This contour plot demonstrates the mechanics of axis assignment and plotting.
It deliberately avoids peak assignment or quantitative interpretation because
the data are synthetic and contain only simple test values.
