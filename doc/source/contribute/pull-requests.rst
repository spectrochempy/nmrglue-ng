Submit a pull request
=====================

Keep each pull request focused. Use the repository's
`title prefixes and checks
<https://github.com/spectrochempy/nmrglue-ng/blob/master/CONTRIBUTING.md#commit-and-pull-request-prefixes>`_,
such as ``FIX:`` for bug fixes or ``DOC:`` for documentation.

Describe the problem, what changes for users, and the commands you ran
to verify it. Include a reproducer for a bug fix and identify any tests
that require external data or software. Add an entry under Unreleased
in ``CHANGELOG.md`` for user- or developer-visible changes.

For documentation changes, link the Read the Docs preview once it
builds and point reviewers to the pages that changed. For reader and
processing changes, include the evidence for any new scientific
convention or changed expected result.
