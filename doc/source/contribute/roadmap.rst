Development roadmap
===================

Current work focuses on validating readers and processing against reference
data, improving test coverage with redistributable fixtures, and documenting
the formats and workflows users can rely on.

- Validate axis calibration and array layout for Bruker, Tecmag, JCAMP-DX,
  and NMRPipe cases where independent references are available.
- Expand self-contained coverage for readers and processing. Record the
  provenance and scope of new fixtures as described in :doc:`testdata-policy`.
- Continue reviewing format references and tutorials so that examples show
  the supported operations, limits, and expected results.

See the project's `open issues
<https://github.com/spectrochempy/nmrglue-ng/issues>`_ for specific proposals and
known limitations, and :doc:`../whats-new` for changes already delivered.
