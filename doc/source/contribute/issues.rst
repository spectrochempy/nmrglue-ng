Report an Issue
===============

Use the `nmrglue-ng GitHub issue tracker
<https://github.com/spectrochempy/nmrglue-ng/issues>`_ to report bugs, request
features, or discuss documentation gaps.

Before opening an issue
-----------------------

- Check whether a similar issue already exists.
- Include the installed ``nmrglue-ng`` version or the commit you tested.
- Include your Python version, operating system, and relevant optional
  dependencies.
- For file-format or processing issues, identify the data format and whether
  external software such as NMRPipe, TopSpin, Sparky, or SIMPSON is involved.
- Do not attach private, proprietary, or redistribution-restricted data unless
  you have permission to share it publicly.

Useful bug report details
-------------------------

- A minimal code example that reproduces the problem.
- The exact traceback or incorrect output.
- The expected behavior.
- Whether the issue reproduces with a small synthetic or public fixture.
- Any relevant provenance for external data or reference software results.

Security or private data
------------------------

If the problem requires private data, open a public issue with the smallest
non-sensitive description first and explain that the reproducer cannot be shared
publicly. Maintainers can then decide how to proceed.
