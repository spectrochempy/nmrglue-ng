###########################
Examples from JBNMR article
###########################

These examples were published with the nmrglue paper. Their code uses the
``nmrglue`` import API, which is also provided by the current nmrglue-ng
distribution. The full reference for the article is:

J.J. Helmus, C.P. Jaroniec,
Nmrglue: An open source Python package for the analysis of multidimensional
NMR data,
J. Biomol. NMR,
2013,
10.1007/s10858-013-9718-x


.. _article: http://dx.doi.org/10.1007/s10858-013-9718-x

These listings are used throughout the :doc:`tutorial <../tutorials/index>`.
This index retains their publication order for readers following the article.
Each example links to the original data and shows a result where available.
Downloads are hosted by the Google Code Archive. The displayed sizes
refer to the compressed ZIP files.
