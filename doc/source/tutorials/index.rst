Tutorials
=========

These tutorials are executable MyST-NB notebooks stored as Markdown text so
changes remain reviewable in Git. They use small, versioned, synthetic NMRPipe
fixtures from the test suite and state that provenance explicitly.

The legacy tutorial is still available while the tutorial-first organization is
being evaluated.
