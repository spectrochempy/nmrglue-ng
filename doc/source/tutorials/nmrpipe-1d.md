# 1D NMRPipe data: read, inspect, and plot

**{nb-download}`Download notebook (.ipynb) <nmrpipe-1d.ipynb>`**
· {download}`Download synthetic data (nmrpipe_1d_freq.fid) <../../../tests/fixtures/fileio/data/nmrpipe_1d_freq.fid>`

This tutorial starts with a small **synthetic** NMRPipe 1D spectrum, reads it
with nmrglue-ng, constructs the spectral axis, and plots intensity against
chemical shift.

The fixture is versioned in this repository at
`tests/fixtures/fileio/data/nmrpipe_1d_freq.fid`. It was generated by
`tests/fixtures/fileio/create_test_data_nmrpipe.sh` with NMRPipe from synthetic
time-domain data. It is not a real acquisition.

Relevant API entries: {func}`nmrglue.fileio.pipe.read`,
{func}`nmrglue.fileio.pipe.guess_udic`, and
{func}`nmrglue.fileio.fileiobase.uc_from_udic`.

## 1. Prepare your working folder

Download both files above into the same folder, keeping their filenames.
Use a Python environment with nmrglue-ng, Matplotlib, and a Jupyter frontend
installed. For this release candidate, install the wheel from the
[v1.0.0rc1 release](https://github.com/spectrochempy/nmrglue-ng/releases/tag/v1.0.0rc1)
with `python -m pip install /path/to/nmrglue_ng-1.0.0rc1-py3-none-any.whl`,
then install the notebook tools with `python -m pip install matplotlib jupyterlab`.
Launch `jupyter lab` from the download folder, select that environment's kernel,
and run the notebook from top to bottom.

The code first looks in the current working folder. The fallback to the
repository fixture is only for building the documentation from its sources.

## 2. Read the spectrum

```{code-cell} ipython3
from pathlib import Path

import matplotlib.pyplot as plt
import nmrglue as ng


def find_data_file(filename):
    local_path = Path(filename)
    if local_path.is_file():
        return local_path
    for candidate in [Path.cwd(), *Path.cwd().parents]:
        fixture = candidate / "tests/fixtures/fileio/data" / filename
        if fixture.is_file():
            return fixture
    raise FileNotFoundError(
        f"Download {filename} into the notebook's working folder: {Path.cwd()}"
    )


path = find_data_file("nmrpipe_1d_freq.fid")
dic, data = ng.pipe.read(path)

print(f"Number of spectral points: {data.size}")
print(f"Array data type: {data.dtype}")
print(f"First four intensities (arbitrary units): {data[:4]}")
```

The file stores a frequency-domain, real-valued 1D array. The first two points
were set to simple values by the fixture-generation script so reader behaviour
is easy to inspect.

## 3. Construct the chemical-shift axis

```{code-cell} ipython3
udic = ng.pipe.guess_udic(dic, data)
axis = ng.fileiobase.uc_from_udic(udic)
ppm = axis.ppm_scale()

print(f"Dimension label: {udic[0]['label']}")
print(f"Spectral width: {udic[0]['sw']:.2f} Hz")
print(f"Observation frequency: {udic[0]['obs']:.2f} MHz")
print(f"Frequency-domain data: {udic[0]['freq']}")
print(f"First and last sampled shifts: {ppm[0]:.3f}, {ppm[-1]:.3f} ppm")
```

The universal dictionary records the direct dimension (`H1`), spectral width in
Hz, observation frequency in MHz, and that the data are already in the frequency
domain. `uc_from_udic()` turns those values into a unit-conversion object. The
plot below uses ppm because that is the usual axis for an assigned 1D spectrum;
the axis is reversed so high ppm appears on the left.

## 4. Plot intensity against chemical shift

```{code-cell} ipython3
fig, ax = plt.subplots(figsize=(7, 3))
ax.plot(ppm, data.real, marker="o")
ax.set_xlabel(f"{udic[0]['label']} chemical shift / ppm")
ax.set_ylabel("Intensity / arbitrary units")
ax.set_title("Synthetic 1D NMRPipe fixture")
ax.invert_xaxis()
fig.tight_layout()
plt.show()
```

For real acquisitions, check that the carrier, observation frequency, and
spectral width in the file header match the experiment before interpreting the
ppm scale. This synthetic fixture is useful for documenting mechanics, not for
scientific conclusions about a sample.
