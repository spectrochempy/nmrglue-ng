Additional resources
====================

Detailed information about the ``nmrglue`` import modules and their functions
is available in the :ref:`API reference <reference_guide>` for nmrglue-ng or
through Python's built-in help system:

    >>> help(ng.pipe.read)

Use the :doc:`task index <../how-to/index>` to jump to a workflow, or the
:doc:`JBNMR index <../jbnmr_examples/index>` to find a listing by its position
in the article. The following packages provide additional reference material:

* `NumPy <https://numpy.org/doc/stable/>`_
* `SciPy <https://docs.scipy.org/doc/scipy/>`_
* `Matplotlib <https://matplotlib.org/stable/>`_
* `h5py <https://h5py.org/>`_
