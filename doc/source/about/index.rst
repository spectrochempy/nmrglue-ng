About
=====

``nmrglue-ng`` is an independent continuation of historical nmrglue. The project
preserves attribution to Jonathan J. Helmus and the nmrglue community while
maintaining the established Python import name, ``nmrglue``.

This prototype evaluates documentation architecture for the 1.0.0 line. It does
not remove the existing examples, API reference, or development notes.
