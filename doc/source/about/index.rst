About
=====

``nmrglue-ng`` is an independent continuation of historical nmrglue. The project
preserves attribution to Jonathan J. Helmus and the nmrglue contributors while
maintaining the established Python import name, ``nmrglue``.

Project and package names
-------------------------

This documentation uses ``nmrglue-ng`` for the current project and the
distribution installed with package managers. It uses ``nmrglue`` for the
Python import, module paths, and API names used in code. References to the
historical project are identified as historical or upstream nmrglue; original
paper titles and archive links retain their original names.

Project goals
-------------

- Preserve the established API exposed through the ``nmrglue`` import where
  practical.
- Keep the distribution identity clear: install ``nmrglue-ng``, import
  ``nmrglue``.
- Improve reproducibility and test-data accounting before expanding public
  claims.
- Modernize documentation incrementally while preserving historical attribution.
