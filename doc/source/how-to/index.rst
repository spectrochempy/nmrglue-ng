How-to guides
=============

This section keeps the historical examples available while the public
documentation is modernized. Some examples will become executable tutorials,
some will become focused how-to guides, and some will remain legacy reference
material until their data provenance and expected outputs are reviewed.

The pages below are inherited reStructuredText examples, not a configured
Sphinx-Gallery build.

They originate in historical nmrglue documentation. Their code uses the
compatible ``nmrglue`` import, provided by the current nmrglue-ng distribution;
some download links still point to original example archives.
