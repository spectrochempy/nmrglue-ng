# Explore a spectrum interactively

Use a static plot first to settle the axis and contour conventions.
Interactive views are useful when the next operation depends on a position
you choose while inspecting the spectrum.

## From a trace to a contour map

Begin with the 1D example to learn the controls on a single trace. Use the
2D example to explore cross-peaks and adjust the displayed region. Record
the chosen bounds if they will be reused for quantification.
