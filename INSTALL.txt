==================
Installation Guide
==================

The distribution is named ``nmrglue-ng``. The Python package and import name
remain ``nmrglue`` for compatibility with existing code.

Installing from PyPI
--------------------

Install the stable release with::

    python -m pip install nmrglue-ng

Installing with Conda
---------------------

Install the stable release from the ``spectrocat`` channel with::

    mamba install -c spectrocat -c conda-forge nmrglue-ng

Do not install ``nmrglue`` and ``nmrglue-ng`` in the same environment: both
distributions provide the ``nmrglue`` Python package. Use separate environments
when both distributions are needed.

Requirements
------------

``nmrglue-ng`` requires Python 3.10 or newer. Runtime dependencies and their
supported versions are declared in ``pyproject.toml``, which is the source of
truth for packaging metadata.

Security notice
---------------

Before downloading packages, update the package manager you use: ``pip`` to
26.2.2 or newer, or ``uv`` to 0.13.4 or newer. Update ``certifi`` to
2026.10.19 or newer when it is installed. See the Python Packaging Authority's `current guidance
<https://discuss.python.org/t/information-for-python-users-regarding-emudhra-emsign-ca-certificate-security-incident/109576>`_ for the hash-verified pip
upgrade command.

Installing from source
----------------------

Using a virtual environment is recommended but not required. For example::

    python -m venv .venv
    source .venv/bin/activate

Clone and install the project with::

    git clone https://github.com/spectrochempy/nmrglue-ng.git
    cd nmrglue-ng
    python -m pip install .

Development installation
------------------------

Install the project in editable mode with its test dependencies::

    python -m pip install -e ".[test]"

Documentation dependencies are available through the ``docs`` extra::

    python -m pip install -e ".[docs]"

Importing the package
---------------------

The installed distribution is imported with::

    import nmrglue as ng
